## [Unreleased]

### Breaking changes

- Replaced the UtterPlan-aware document pipeline with `PocketRuntime` synthesis requests for already-prepared speakable text. Document parsing, semantic speech preparation, logical voice roles, pauses, markers, AudioJob creation, composition, and final mastering now belong to the caller and its orchestration/composition layers.
- Removed planner, document-unit streaming, composition APIs, planner configuration and provenance, and compatibility aliases. Use `PocketRuntime.synthesize()` or `synthesize_text()` with a concrete `PreparedVoice`; model-limit chunks remain request-local engine details.
- Removed Utterplan and AudioCompose as PocketSynth runtime dependencies. PocketSynth can be imported and used for Pocket synthesis without those packages or SSMD.
